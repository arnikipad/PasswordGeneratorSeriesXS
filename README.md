# Password Generator — Series X|S Edition

Original Visual Studio C# WinForms password-generator concept with a green animated startup screen.

## Requirements

- Visual Studio 2022
- .NET 8 SDK
- Windows

## Build

Open `PasswordGeneratorSeriesXS.csproj` in Visual Studio and choose:

**Build → Build Solution**

The application automatically loads and plays:

`Assets/startup_real.wav`

The WAV is the audio extracted from the video supplied with this project.

## Startup sequence

1. Green boot screen appears.
2. `startup_real.wav` plays.
3. Animated progress bar advances.
4. Password generator opens.
5. A cryptographically random password is generated.

This project is an original password-generator UI concept and is not affiliated with Microsoft or Xbox.
